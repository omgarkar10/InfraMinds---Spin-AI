## 1. Overview & Processing Modes

To guarantee transparency and prevent mock heuristics from being falsely presented as live AI reasoning, all pipeline responses must explicitly declare their operational execution mode:

| Mode Identifier | Semantics | When Issued |
|:---|:---|:---|
| `LIVE_AI` | Output generated by Gemini 2.5 Flash via Google ADK live runner. | Active GCP / ADK connection with valid API credentials. |
| `DEMO_FALLBACK` | Output produced by deterministic keyword heuristics and mock GIS data. | Missing credentials, network timeout, or offline hackathon demo. |
| `UNAVAILABLE` | Pipeline failed completely without structured fallback. | Catastrophic internal error or unrecoverable payload corruption. |

## 3. Normalized Pipeline Endpoint Contract

### Endpoint: `POST /api/pipeline/run`

#### Request Payload:
```json
{
  "citizen_id": "cit-101",
  "description": "Continuous water leakage flooding Sector 4 roadway.",
  "source_language": "en",
  "input_source": "web",
  "location": {
    "latitude": 18.5204,
    "longitude": 73.8567,
    "landmark": "Near Sector 4 water tank",
    "district": "Pune",
    "state": "Maharashtra"
  }
}
```

#### Success Response (`200 OK`):
```json
{
  "request_id": "REQ-72AF891B01",
  "status": "completed",
  "processing_mode": "LIVE_AI",
  "parsed_request": { ... },
  "data_context": { ... },
  "priority_recommendation": { ... },
  "execution_duration_ms": 1820
}
```

#### Validation Error Response (`422 Unprocessable Entity`):
```json
{
  "status": "validation_error",
  "detail": [
    {
      "loc": ["body", "description"],
      "msg": "Description must contain at least 5 non-whitespace characters.",
      "type": "value_error"
    }
  ]
}
```

#### Location Required Response (`200 OK` / `awaiting_location`):
```json
{
  "status": "awaiting_location",
  "request_id": "REQ-72AF891B01",
  "prompt": "Where is the issue located? Share GPS pin or nearest landmark.",
  "intake_payload": { ... }
}
```

## 4. Contract Governance & Unresolved Decisions

### 4.1 Schema Correction Pass (Verified & Implemented in `schemas.py`)
- **`Location`**: Requires both coordinates together or neither. Rejects non-finite values (NaN/Inf). Preserves legitimate `(0.0, 0.0)` coordinates without substitution.
- **`CitizenRequest`**: Defaults `source_language` to `"auto"`. Rejects blank identifiers. Caps `evidence` list at 10 items.
- **`ParsedRequest`**: Requires explicit `detected_language`. Defaults `processing_status` to `"needs_human_review"`. Allows incomplete location when `awaiting_location`.
- **`CommunityCluster`**: Enforces `dominant_category` membership in `infrastructure_categories`. Rejects count mismatches. Defaults `is_red_zone` to `null`.
- **`DataContext`**: Explicitly represents unknown data quality (`data_quality_score: null`) and unknown provenance (`synthetic_data_flag: null`).
- **`PriorityRecommendation`**: Defaults `model_version` to `null`. Validates score components are non-negative finite numbers.
- **`PolicyAction`**: Retains canonical audit model with required `reviewer_id`, `reviewer_role`, and `recommendation_id`.
