# Code Ownership

To reduce merge conflicts and ensure clear accountability across the 4-member GCC team, ownership of the codebase is divided as follows:

| Area | Owner |
|---|---|
| Frontend API Layer | Member A |
| Citizen Flow | Member B |
| Dashboard | Member C |
| Backend + ADK | Om (Lead) |

When proposing changes that span multiple domains, ensure the respective owners are included in the PR review.
